## 📚 Your OOP Exercise: Books & Authors!

### Step-by-step Instructions (if you want help along the way)

Create each class in its own file, in the same package or folder.

1. Create an `Author` class with a `String name` field.
2. Create a `Book` class with:
   - A `String title` field.
   - An `Author author` field.
   - A `printDetails()` method that prints the title and `author.name`.
3. In `App`'s `main` method, create an `Author` and set their name.
4. Create a `Book`, set its title, and assign your author object to its `author` field.
5. Call `printDetails()`.
6. Change the author's name and call `printDetails()` again. Check that the new name appears.

### 💡 Bonus

Create a second book by the same author. What happens to both books when you change the author's name?
