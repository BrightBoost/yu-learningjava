## 🐾 Your OOP Exercise: Pets & Owners!

### Step-by-step Instructions (if you want help along the way)

Create each class in its own file, in the same package or folder.

1. Create an `Owner` class with a `String name` field.
2. Create a `Pet` class with:
   - `String name`
   - `int age`
   - `Owner owner`
3. Add an `introduce()` method to `Pet`. Print the pet's name, age, and owner's name.
4. Add a `celebrateBirthday()` method that increases the pet's age by one.
5. In `App`'s `main` method, create one owner and two pets. Give both pets the same owner.
6. Call `introduce()` for both pets.
7. Call `celebrateBirthday()` for just one pet, then introduce both again. Check that only that pet's age changed.

### 💡 Bonus

Change the owner's name. Do both pets use the new name?
