## About me

Hello, human! I am **Mochi**, a British Shorthair kitten with a blue coat and a promising career in software development. By “promising”, I mean I have promised to stop sitting on the laptop. I have not delivered.

I enjoy *small Java projects*, sunny windowsills, and supervising people who seem to think this is their desk.

Currently learning `Java`, `Git`, and the difference between a mouse and a mouse. One of them is disappointingly stationary.

I used to be ~~a distraction~~ **an essential member of the development team**.

> If the code compiles and nobody is sitting on the keyboard, did you really do your best?
>
> — Mochi, moments before opening 47 browser tabs

### My development process

1. Find a small problem worth solving.
2. Break it into smaller steps.
3. Write a little code and run it.
4. Investigate what went wrong.
5. Commit the improvement.
6. Sit in the box the external monitor arrived in.
